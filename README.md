# DLSS5-6x-AMD-OptiScaler

AMD + OptiScaler DLSS 5/6x experimental integration project.

本项目用于研究和整理 AMD GPU 环境下通过 OptiScaler 使用 DLSS 相关功能的配置、教程、测试以及兼容性信息。

## 项目内容

- AMD + OptiScaler
- DLSS 5/6x 实验性配置
- Frame Generation 测试
- 游戏兼容性测试
- 配置文件
- 安装与使用教程
- 性能与画质对比

## 使用说明

本项目中的配置和方法主要用于实验与测试。

不同 AMD GPU、驱动版本、Windows 版本以及游戏版本可能存在兼容性差异。

项目仍在持续测试和更新中。
